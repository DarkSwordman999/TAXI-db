# Команды проекта

Полный справочник команд `./help.sh` и `./python_reports.sh`. Краткий обзор — в [README](../README.md), устройство базы — в [DATABASE.md](DATABASE.md).

В Windows вместо `./help.sh` пишите `.\help.cmd`, вместо `./python_reports.sh` — `.\python_reports.cmd`, параметры те же. `./help.sh` без параметров печатает меню.

У каждой SQL-команды есть имя и прежний номер, оба работают одинаково: `./help.sh companies` = `./help.sh 01`.

## Данные

| Команда | Что делает |
|---|---|
| `./help.sh fetch [дней]` | скачать недостающие дни из API Чикаго (по умолчанию проверяются последние 45 дней) |
| `./help.sh load` | загрузить в базу дни, которых в ней еще нет |
| `./help.sh load --all` | перечитать все файлы с поездками |
| `./help.sh rebuild` | пересоздать все таблицы и загрузить все поездки; ручные изменения пропадут |

## Основные задачи

## SQL-файлы

| Команда | Что делает |
|---|---|
| `./help.sh файл.sql [параметр]` | выполнить SQL-файл; параметр доступен в нем как `:arg1` / `:'arg1'` |
| `./help.sh h1 файл.sql [параметр]` | то же через `run_sql.sh` |

Пример: `./help.sh helper/24_search_area.sql Park` — районы, в названии которых есть «Park».

## Python-отчеты

| Команда | Что делает |
|---|---|
| `./python_reports.sh 1 [водитель] [тип_клиента]` | выручка по водителям и типам клиентов |
| `./python_reports.sh 1s [водитель] [тип_клиента]` | то же со звездочкой в углу таблицы |
| `./python_reports.sh 2 [тип_клиента]` | сводные матрицы выручки и числа поездок |
| `./python_reports.sh 3 [--force]` | график выручки и числа поездок по месяцам |
| `./python_reports.sh 4 [водитель] [--force]` | круговая диаграмма выручки по типам клиентов |
| `./python_reports.sh save [--force]` | сохранить все графики в `docs/` |
| `./python_reports.sh all` | все отчеты подряд |

Без кода водителя отчеты берут 15 водителей с наибольшей выручкой. Если график уже сохранен, отчет спрашивает, перезаписать ли его; `--force` перезаписывает без вопроса, а без терминала файл не перезаписывается.

## Коды завершения

Все команды возвращают 0 при успехе и ненулевой код при ошибке: ошибка SQL, неизвестная команда, неверный параметр. На этом построены автотесты `tests/run_all.sh`.
