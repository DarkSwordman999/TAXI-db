## Как это устроено

```mermaid
flowchart LR
    API["🌐 API мэрии Чикаго<br/>все поездки такси"]
    GH["⚙️ GitHub Actions<br/>каждый день"]
    CSV["📦 data/chicago/rides<br/>файл на каждый день"]
    DB[("🐘 PostgreSQL<br/>6 таблиц")]
    SQL["📜 help.sh<br/>70 команд, 56 SQL-файлов"]
    PY["📊 Python-отчеты<br/>и графики"]
    GUI["🖥️ GUI на tkinter"]

    API --> GH --> CSV -->|"./help.sh load<br/>только новые дни"| DB
    DB --> SQL
    DB --> PY
    DB --> GUI
```

Сборщик сам докачивает пропущенные дни и коммитит их в репозиторий. Загрузчик берет из базы список уже загруженных дней и читает только новые файлы, поэтому повторная загрузка занимает секунды. Каждый push проверяют автотесты: они поднимают PostgreSQL, пересобирают базу с нуля и прогоняют все команды, SQL-файлы и отчеты.

### Одна поездка изнутри

Так поездка выглядит в представлении `v_rides_user`, где вместо кодов уже подставлены названия:

```text
код_поездки   | 508396
дата          | 2026-06-12 19:00:00     ← вечер пятницы
водитель      | Водитель №1756
таксопарк     | Flash Cab
оплата        | Банковская карта
откуда        | Ohare                   ← аэропорт
куда          | Loop                    ← деловой центр
расстояние_км | 26.89
время_мин     | 72                      ← 27 км за 72 минуты: пробка видна прямо в данных
стоимость     | 44.75
чаевые        | 10.65
```

### Что заложено в схему

| | |
|---|---|
| 🛡️ **10 правил `CHECK`** | стоимость, пробег и время больше нуля, поездка не кончается раньше начала, у района код от 1 до 77. Неправдоподобная строка в базу не попадет |
| 🔗 **5 внешних ключей** | у каждой поездки есть настоящий водитель, таксопарк и способ оплаты. Удалить водителя, у которого есть поездки, база не даст |
| ♻️ **Повторная загрузка безопасна** | у каждой поездки уникальный `trip_id` из данных города, поэтому загрузить один день дважды невозможно |
| ⚡ **6 индексов** | под частые фильтры: дата, водитель, таксопарк, способ оплаты, районы |
| 🔍 **Поиск по похожим названиям** | расширение `pg_trgm` находит «Flash Cab», даже если ввести «flsh cab» |
| 🕶️ **Обезличенные данные** | город прячет машину за хэшем, округляет время до 15 минут, а место — до района |

### Готовые представления и функции

Два представления: `v_rides_user` (с названиями, для людей) и `v_rides_tech` (с кодами и исходными ID). Шесть функций на PL/pgSQL: выручка водителя, водители выше порога, выручка по таксопаркам и сезонам, средняя выручка таксопарка и сводная таблица. Например, сводная таблица «водители × способы оплаты»:

```sql
SELECT * FROM display_pivot_table()
ORDER BY карта + наличные + приложение + предоплата DESC
LIMIT 3;
```

```text
    водитель    | карта  | наличные | приложение | предоплата
----------------+--------+----------+------------+------------
 Водитель №543  | 277.75 | 26045.53 |      28.58 |     124.75
 Водитель №1912 | 201.94 |  1167.13 |    1403.49 |   23658.45
 Водитель №2211 |  64.25 |  1198.34 |      22.47 |   22205.16
```

У трех водителей с наибольшей выручкой почти все деньги приходят одним способом: у одного наличными, у двух других предоплатой.

Каждое поле, ограничение и функция подробно описаны в [docs/DATABASE.md](docs/DATABASE.md).

## Пример: сколько стоит поездка в аэропорт

```sql
SELECT CASE WHEN откуда = 76 OR куда = 76 THEN 'аэропорт O''Hare' ELSE 'город' END AS поездка,
       count(*)                                     AS поездок,
       round(avg(расстояние_км), 1)                 AS км,
       round(avg(стоимость + чаевые + сборы), 2)    AS средний_чек
FROM ПОЕЗДКИ
GROUP BY 1;
```

```text
     поездка     | поездок |  км  | средний_чек
-----------------+---------+------+-------------
 город           |  575451 |  6.3 |       17.25
 аэропорт O'Hare |  154549 | 24.7 |       57.93
```

Таблицы и поля названы по-русски, и запросы к базе читаются почти как текст. Готовых запросов в проекте 56: JOIN всех видов, подзапросы, оконные функции, запросы с параметрами, UPDATE и DELETE с состоянием до и после.

```bash
./help.sh                 # меню всех команд
./help.sh top-drivers     # топ-10 водителей по выручке
./help.sh driver 12       # сводка по водителю № 12
./help.sh func-pivot      # водители × способы оплаты
./python_reports.sh all   # все отчеты и графики
```

## О данных

Источник — [Chicago Data Portal, Taxi Trips](https://data.cityofchicago.org/resource/ajtu-isnz.json): все поездки лицензированных такси Чикаго. Город публикует их помесячно и обезличивает: машина указана хэшем, время округлено до 15 минут, места — до района.

В Чикаго около 18 000 поездок в день, в репозиторий попадает равномерная выборка из 2000 поездок за каждый день. Доли и средние по выборке близки к картине по всему городу, а суммы относятся только к выборке:

| | Выборка в базе | Все такси Чикаго |
|---|---:|---:|
| поездок | 730 000 | 6 546 819 |
| выручка по счетчику | $15,6 млн | $139,3 млн |
| выручка с чаевыми и сборами | $19,1 млн | $171,4 млн |

Период — с 01.10.2025 по 30.09.2026. Новые месяцы приходят сами: `git pull` и `./help.sh load`.
